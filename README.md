# Hire24 – Recruitment Platform

Hire24 is a recruitment platform designed to simplify the hiring process by connecting job seekers with recruiters. Initially focused on the Mumbai job market, particularly Andheri West and East, it aims to make local recruitment faster, more accessible, and efficient.

## Features

- Job seeker registration and authentication
- Recruiter registration and authentication
- Job posting and management
- Candidate discovery and recruitment
- Voice and text-based communication
- Admin dashboard and management
- Location-focused recruitment

## Tech Stack

**Frontend:** React.js, JavaScript, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Authentication:** JWT, HTTP-only cookies

## Project Structure

- `client/` – Frontend application
- `server/` – Backend APIs and business logic

## Getting Started

1. Clone the repository.
2. Install frontend and backend dependencies.
3. Configure environment variables.
4. Start the backend server.
5. Start the frontend application.

## Environment Variables

Create appropriate `.env` files for the client and server.

Never commit API keys, database credentials, JWT secrets, or other sensitive information.
